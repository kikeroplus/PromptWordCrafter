# PromptWordCrafter

PySide6 製のテキストファイル検索・置換・直接編集ツールです。フォルダ内のテキストファイルを一覧表示し、選択したファイルの内容を右側の編集欄で確認・編集できます。

`PromptManager` プロジェクトの `text_replace_tool.py`（Text Preview Search Replace）が持つ機能をすべて引き継いだうえで、今後プロンプト作成支援向けの機能を追加していくためのベースアプリです。

## セットアップ

```powershell
pip install -r requirements.txt
```

## 起動方法

`run_app.bat` をダブルクリックします。

または、このフォルダで次のコマンドを実行します。

```powershell
python main.py
```

すでに起動しているときにもう一度起動すると、新しくは開かず、起動中のウィンドウを手前に出します。

## 基本的な使い方

1. 上部のフォルダ欄で対象フォルダを指定します。
2. 「選択」ボタンでフォルダを選ぶか、フォルダ欄にパスを入力して Enter を押します。
3. 左側のファイル一覧から編集したいテキストファイルを選択します。
4. 右側の編集欄にファイル内容が表示されます。

対象になる拡張子は `.txt`, `.log`, `.md`, `.csv`, `.tsv`, `.json`, `.xml`, `.html`, `.htm`, `.css`, `.js`, `.py`, `.ini`, `.cfg`, `.conf`, `.yml`, `.yaml` です。

## 検索

検索文字列を入力して「検索」ボタンを押すと、現在表示中のファイル内を検索します。一致箇所はハイライト表示され、最初の一致箇所へスクロールします。

検索文字列を入力すると、左側のファイル一覧も自動的にスキャンされます（入力後 250ms 待ってから実行）。検索文字列を含むファイルは、淡色 `#edf5ef` でハイライト表示されます。

検索後は、置換ボタンと同じように左側のファイル一覧へフォーカスが戻ります。検索欄で Enter を押しても検索できます。編集欄でテキストを選択すると、選択した文字列が検索欄に自動的にコピーされます。

## 置換

検索文字列と置換文字列を入力して「置換」ボタンを押すと、現在表示中のファイルの編集欄内で一致箇所をまとめて置換します。置換は編集欄への変更なので `Ctrl+Z` で元に戻せます。内容を確認してから「保存」でファイルへ反映してください。

保存時は、初回だけ元ファイルと同じ場所に `.bak` バックアップを作成します。たとえば `sample.txt` を保存した場合、`sample.txt.bak` が作成されます。

検索・置換は大文字小文字を区別します。検索欄・置換欄では `Ctrl+Enter` で改行を入力でき、複数行の検索語も使えます。空白は NBSP と、改行は CRLF / CR / LF / U+2028 / U+2029 と同一視して判定します。

「フォルダ一括置換」ボタンは、フォルダ内の全ファイルを同じ判定で置換してファイルへ直接書き込みます（`.bak` を作成し、`Ctrl+Z` では戻せません）。

## 直接編集と保存

右側の編集欄は直接編集できます。編集後は「保存」ボタンで現在のファイルへ保存します。

ショートカットでも保存できます。

```text
Ctrl+S
```

保存時も、初回だけ `.bak` バックアップを作成します。

## 未保存の変更

未保存の編集がある状態で次の操作をしようとすると、保存確認が表示されます。

- 別のファイルを選択する
- フォルダを再読み込みする
- 別のフォルダを選ぶ
- アプリを閉じる

キャンセルを選ぶと操作は中止され、編集中のファイルに戻ります。

## ファイルのドラッグ&ドロップ

左側のファイル一覧から選択したファイルを Windows エクスプローラーへドラッグすると、そのままコピーできます。`Ctrl` / `Shift` で複数選択したファイルもまとめてドラッグコピーできます。

## 設定保存

アプリ終了時に次の設定が `promptwordcrafter_settings.json`（実行ファイルと同じフォルダ）に保存されます。

- 最後に開いたフォルダ
- 検索文字列
- 置換文字列
- ウィンドウの位置とサイズ
- 翻訳 (AI) のオン/オフ、訳す向き、サーバーURL、モデル名
- エンハンサー (AI) で選んでいるプリセットと、LLM のモデル名

## 対応エンコーディング

ファイル読み込み時は次の順で文字コードを判定します。

```text
utf-8-sig, utf-8, cp932, utf-16, latin-1
```

保存時は、読み込み時に判定された文字コードで保存します。

## フォルダツリー

ファイル一覧の左側にフォルダツリーを表示します。フォルダをクリックすると、そのフォルダ（直下のみ、非再帰）がファイル一覧に反映されます。

## 一括操作

コントロールバーの下に一括操作ボタンがあります。いずれも対象はフォルダ直下のファイルのみで、サブフォルダの中身は対象になりません。

- **新規ファイル**: 現在のフォルダに空のテキストファイルを作成します。ファイル名は一覧の最後のファイル名の末尾の番号を +1 したもの（桁数・拡張子は維持。例: `haikei2-010.txt` → `haikei2-011.txt`）が初期表示され、変更もできます。拡張子を省略すると `.txt` になります。
- **一括リネーム**: ファイル一覧で複数選択している場合はその選択ファイル、未選択（1件以下の選択）の場合はフォルダ内の全ファイルを対象に、プレフィックス・開始番号・桁数を指定して連番形式（例: `scene_001.txt`）にリネームします。プレビューを見ながら調整できます。
- **文字列追加**: 指定した文字列をファイルの先頭または末尾に追加します。対象は「現在のファイルのみ」または「フォルダ内の全ファイル」から選べます。追加時も `.bak` バックアップが作成されます。
- **文字列削除**: 指定した文字列をファイルから削除します。対象は「現在のファイルのみ」または「フォルダ内の全ファイル」から選べます。削除時も `.bak` バックアップが作成されます。
- **.bakファイル削除**: 現在のフォルダ直下にある `.bak` ファイルをまとめて削除します。件数を確認するダイアログが表示されます。
- **文字列成型**: 現在編集中のファイルの内容に対して、「。」「.」の直後に改行を追加します。整形後は編集欄に反映されるだけなので、内容を確認してから「保存」してください。

## 生成 (ComfyUI)

テキストファイルの本文をプロンプトにして、ローカルの ComfyUI で画像・動画を生成します（t2i / t2v）。挙動は J-Rate の生成機能（`J-Rate\docs\generation-standard.md`）に合わせています。

ファイル一覧の右クリックメニュー、またはコントロールバーの「生成 (ComfyUI)」グループから使います。

- **生成する (ComfyUI)...**: 選択中のファイルから生成します。複数選択しているときは「選択中のファイルを生成する (N 件)...」になります。
- **一覧のファイルをまとめて生成する (N 件)...**: 一覧のすべてのファイルから生成します。
- **生成時の設定...**: そのファイルから最後に生成したときの設定を表示します。「この設定で生成する...」でやり直せます。
- **生成ジョブの一覧...** (`Ctrl+J`): 進み具合の確認とキャンセル。ジョブは処理する順に並びます。実行中のものは色付きの太字で、一覧の上にも「実行中: (ファイル名)」が出ます。完了したものには生成にかかった時間が出ます。
- **生成の設定...**: 接続先・ワークフロー・プロンプト・ベースプロンプト・セットの登録、エクスポート / インポート。

フォルダツリーのフォルダを右クリックしても、そのフォルダのテキストをまとめて生成できます（右クリックしただけではフォルダは開きません）。

- **このフォルダのテキストをまとめて生成する (N 件)...**: そのフォルダ直下のテキストファイルから生成します。
- **サブフォルダも含めてまとめて生成する...**: サブフォルダ配下もすべてたどります（`.` で始まる隠しフォルダは除く）。件数は生成の画面の題に出ます。
- **このフォルダの生成結果を「生成結果」フォルダへ移す...**: 前の版でテキストと同じフォルダに保存した生成結果を、そのフォルダの中の `生成結果` フォルダへ移します。結果と同じ名前の `.txt`（ImageMimicArt などで読み取った説明）も一緒に移し、生成の記録（PromptWordCrafter と ImageMimicArt）も付け替えます。
- **エクスプローラーで開く**
- 生成結果は、それぞれ元のテキストファイルのフォルダの中の `生成結果` フォルダにできます。サブフォルダ込みの生成では `生成結果` フォルダはたどりません（中の `.txt` は画像の説明なので）。本文が空のファイルは除き、合計が 30 件を超えるときは確認します。

決まりごと:

- **テキストファイル 1 つが 1 本のプロンプト**です。本文をそのままワークフローのプロンプトに入れ、ベースプロンプトを改行をはさんで後ろに付けます。
- 表示中のファイルは、保存前の編集も含めて編集欄の内容を使います。ほかのファイルも編集欄と同じ表記（NBSP→空白、改行→LF）にそろえてから送ります。
- 生成の画面では本文を見せるだけで、書き換えられません（書き換えるときは編集欄で）。セットとパラメーターの貼り付けで変わるのは、接続先・ワークフロー・長さだけです。
- まとめて生成では、ファイルごとの本文をそれぞれ送ります。本文が空のファイルは除きます。1 件のときに本文が空なら生成できません。
- 「生成時の設定」の「この設定で生成する...」は、接続先・ワークフロー・長さを記録から取り、プロンプトは今のファイルの本文を使います。
- ワークフローは ComfyUI の「Export (API)」で保存した JSON を登録します。どこかの文字欄に `{prompt}` と書いておくと、そこを本文に置き換えます (どのノードでも可。前後に書いた語は残ります。目印があるときは下の自動判定は使いません)。目印がなければ、本文は `prompt` 入力と、タイトルに Positive / User Prompt とある文字列ノード（ComfyUI のテンプレートの「Text (User Prompt)」など）に入ります。どちらもなければ `CLIPTextEncode`（複数ならタイトルに Positive とあるもの）に入ります。タイトルに Negative とあるノードには入れません。If/Else Switch の使われない側など、画像に使われない場所は数えません。入れる場所が決まらない (または使われない場所しかない) ワークフローは登録・生成できません。seed は毎回ランダムになります。
- 出来たファイルはテキストファイルのフォルダの中の `生成結果` フォルダに `(元の名前)_t2i.png` / `(元の名前)_video.mp4` で保存します（同じ名前があれば ` (2)` などを付けます）。プロンプトのフォルダには手で作ったテキストだけを置くためです（結果の画像を ImageMimicArt などで元画像にすると、その隣に説明の `.txt` ができるので、同じフォルダだとプロンプトと混ざります）。1 件だけの生成なら、終わったあと関連付けられたアプリで開きます（設定で切り替え可）。
- 同じ接続先には同時に 2 件まで送り、残りは待機させます。
- 生成ジョブが残っているときに閉じようとすると「残して閉じる / 捨てて閉じる / やめる」を選べます。どちらで閉じても、ComfyUI 側で実行中・順番待ちのものは止まりません。
- 終わっていないジョブは `%APPDATA%\PromptWordCrafter\comfy_jobs.json` に随時書いておきます。「残して閉じる」で閉じたときや PC が落ちたときは、次に起動したときに「続きから始める / ジョブを中断」を選べます。
  - 続きから始める: ComfyUI に依頼済みのものは、完成していれば結果を受け取り、順番待ち・実行中ならそのまま待ちます。ComfyUI 側に残っていなければ（ComfyUI も再起動したときなど）依頼し直します（seed は変わります）。待機中だったものは改めて依頼します。元のテキストファイルが見つからないものは除きます。
  - ジョブを中断: 残りのジョブを取り消し、ComfyUI に依頼済みのものは待ち行列から外します。
- 生成の途中で ComfyUI を再起動して実行が消えたときも、依頼し直します。
- 生成の画面の「＋ ベースプロンプト」のチェックを外すと、ベースプロンプトを付けずに送ります。チェックの状態は覚えておきます（生成を始めたときだけ）。ベースプロンプトが空のときは出しません。
- 生成の画面の「エンハンサー」でエンハンサーを選ぶと、本文を AI で盛ってから送ります（下の「エンハンサー」の章）。
  - ジョブの番が来たら、ComfyUI に送る前に盛ります（ジョブ一覧に「AI で盛っています...」と出ます）。ジョブごとに盛るので、回数を増やすと毎回違う盛り方になります。ベースプロンプトは盛らずに後ろに付けます。
  - エンハンサーの中身（指示文・接続先・モデル）は登録した時点のものを使います。盛った本文はジョブに残すので、続きから始めるときは盛り直しません。
  - 盛れなかったときはジョブの失敗にします（元の本文のままは送りません）。盛っている間もキャンセルできます。一時停止したときは、盛った本文を持ったまま待機に戻ります。
  - 記録には元の本文と、エンハンサーの名前・盛った本文を残します。「生成時の設定」で盛った本文を見られます。「旧」の判定は元の本文で行います。「この設定で生成する...」では同じ名前のエンハンサーを選び、盛り直します。
  - 前回選んだエンハンサーを覚えておきます（生成を始めたときだけ）。セットとパラメーターのコピーには含めません。

### 生成結果

編集欄の下に、表示中のテキストから生成した画像・動画のサムネールを新しい順に横一列で並べます（ホイールで横スクロール）。動画には ▶、今の本文とは違う前の本文で生成したものには「旧」の印が付きます。

- 結び付けは生成の記録を正にします。記録のないものは、`生成結果` フォルダとテキストと同じフォルダ（前の置き場所）から、名前が `(テキストの名前)_t2i` / `_video` で始まるファイルを拾います（この場合「旧」の判定はしません）。
- クリックすると、一覧の上に大きく表示します。表示中に別のサムネールをクリックするか `←` `→` (小窓の上ではホイール) で切り替え、同じものをもう一度クリック / `Esc` / 小窓や他の場所をクリックで閉じます。表示中に `Del` で消すと次のものを表示します。
- ダブルクリック / `Enter` で関連付けられたアプリで開きます。右クリックで「開く」「生成時の設定...」「エクスプローラーで開く」「ファイルを削除 (ごみ箱へ)」。`Del` でも削除できます（複数のときだけ確認）。
- サムネールを他のアプリへドラッグすると、ファイルとして渡せます（コピーのみ）。
- 一括リネームでテキストの名前を変えると、生成結果のファイル名（`旧の名前_t2i.png` → `新しい名前_t2i.png`）と生成の記録も合わせて変えます。`生成結果` フォルダの結果に付いている説明の `.txt` と、その結果を元画像にした ImageMimicArt の記録も付け替えます。エクスプローラーで名前を変えた場合も、送った本文が今の本文と同じ記録から見つけます。
- 接続先・ワークフロー・ベースプロンプト・エンハンサー・LLM のサーバーURL は `%APPDATA%\GenCommon\` に置き、J-Rate・ImageMimicArt と共有します（どのアプリで変えても、ほかのアプリに効きます）。セット・前回選んだもの・生成の記録・ジョブは `%APPDATA%\PromptWordCrafter\` です。エクスポートした設定は 3 つのアプリで互いにインポートできます。
- 「生成の設定」の接続先のタブで、接続先ごとに「ワークフローのフォルダ」（`\\RAVEN\SharBox\comfyui-api\kiwi` など）を決めると、そのフォルダにあるワークフローはその台用として扱います。一覧の名前の後ろに［KIWI］のように台の名前が付き、生成の画面でワークフローを選ぶと接続先もその台になります。台が違う組み合わせのときは注意を出します。ワークフローのタブの「フォルダから登録...」で、フォルダにあるまだ登録していない JSON をまとめて登録できます（名前はファイル名）。
- 「生成の設定」の「共有の置き場所...」で、共有するものの置き場所をネットワークの共有フォルダ（`\\RAVEN\SharBox\GenCommon` など）にできます。ほかの PC でも同じフォルダにすると、PC の間でも同じ設定になります。この PC の今の設定のうち、そのフォルダにないものだけを足します。`%APPDATA%\GenCommon\` には最後に読めた内容の写しを残し、フォルダに繋がらないときはそれを表示します（その間は変更を保存しません）。使用中・前回選んだものは PC ごとで、ほかの PC で並べ替えても同じものを指し続けます。
- 生成と読み取りの部品は ImageMimicArt と共通の `..\GenCommon\gencommon` を使います（このフォルダと同じ `AI_projects` に並べて置きます。EXE を作るときも取り込みます）。決まりごとは J-Rate の `docs\generation-standard.md`。

## 翻訳 (AI・見るだけ)

コントロールバーの「翻訳 (AI)」グループで「翻訳する」をオンにすると、表示中のテキストの訳を編集欄の右下の小窓に出します。ファイルを切り替えるたびに訳し直します（訳が出るまで少し時間がかかります）。訳はファイルには書き込みません。

- 訳す向きはふだん AI が判別します（日本語以外 → 日本語、日本語 → 英語）。うまく判別されないとき（英語 → 英語になるなど）は、小窓の「日本語に」「英語に」を押すと、訳す先をはっきり指示して訳し直します。押したボタンはオンのまま残り、ファイルを切り替えてもその向きで訳します。もう一度押すと自動判別に戻ります。タグの区切り、`(word:1.2)` のような重み付け、`<lora:...>` などの記法はそのまま残すよう指示しています。
- 接続先は LM Studio などの OpenAI 互換 API です。「翻訳の設定」でサーバーURLとモデル名を変えられます（既定は TranslateText と同じ `http://192.168.11.6:1234/v1` / `qwen2.5-14b-instruct-uncensored`）。「モデル取得」「接続テスト」もあります。
- ファイルを続けて切り替えたときは、止まったところのファイルだけを訳します。一度訳した本文は覚えておき、もう一度は依頼しません。
- 小窓のコピーアイコンで訳を丸ごとクリップボードにコピーします（押すと少しの間 ✓ に変わります）。一部だけなら本文を選んで `Ctrl+C` でもコピーできます。
- 小窓の「再翻訳」で編集欄の今の内容（保存前の編集も含む）を訳し直します。「×」で翻訳をオフにします。

## エンハンサー (AI・見るだけ)

コントロールバーの「エンハンサー (AI)」グループでエンハンサーを選んで「盛る」を押すと、編集欄の今の内容（保存前の編集も含む）をローカル LLM に渡して書き足してもらい、結果を編集欄の右上の小窓に出します。ファイルには書き込みません。コピーアイコンでコピーして使います。

- 生成 AI のモデルごとに推奨される書き方が違うので、「設定」でモデルごとのエンハンサーを最大 20 個登録して切り替えます。1 つのエンハンサーは、名前・指示文 (system)・送る文の雛形 (user)・temperature です。
  - 指示文には、モデルごとに推奨されている指示文をそのまま貼ります。
  - 雛形の `{prompt}` が編集欄の内容に置き換わります（ふつうは `{prompt}` だけで十分です）。`{prompt}` がないときは、雛形のあとに編集欄の内容を付けて送ります。
  - 登録は「プリセットを保存」「削除」「▲ 上へ」「▼ 下へ」でその場で書き込みます（キャンセルしても残ります）。`%APPDATA%\GenCommon\enhancer_presets.json` に保存します (3 つのアプリで共有)。初めて使うときは、1・2 番に例（自然文・タグ）が入っています。
- 接続先は「翻訳の設定」のサーバーURLを使います。LLM のモデルは翻訳と別に選べます（初めは翻訳と同じモデル）。
- 小窓の「もう一度」で盛り直します（毎回違う結果になります）。盛っている間は「盛る」を押せません。結果はファイルを切り替えても残るので、新しいファイルに貼ることもできます。「×」で閉じます。
- 結果の全体を囲むコードブロックや引用符、`<think>...</think>` は取り除きます。
- 登録したエンハンサーは、生成するときにも使えます（「生成 (ComfyUI)」の章）。

## MiniMax H3 タグのハイライト

`<d> ～ </d>` のブロックは常時ハイライト表示されます（複数行にまたがる場合も対応）。タグ内の `[...]`（角括弧）で囲まれた部分は、セリフ文字部分としてさらに青色で強調表示されます。
