# PromptWordCrafter

PySide6 製のテキストファイル検索・置換・直接編集ツールです。フォルダ内のテキストファイルを一覧表示し、選択したファイルの内容を右側の編集欄で確認・編集できます。

`PromptManager` プロジェクトの `text_replace_tool.py`（Text Preview Search Replace）が持つ機能をすべて引き継いだうえで、今後プロンプト作成支援向けの機能を追加していくためのベースアプリです。

## セットアップ

```powershell
pip install -r requirements.txt
```

## 起動方法

`run_app.bat` をダブルクリックします。

または、このフォルダで次のコマンドを実行します。

```powershell
python main.py
```

すでに起動しているときにもう一度起動すると、新しくは開かず、起動中のウィンドウを手前に出します。

### MuseFactory から開く

MuseFactory (`..\MuseFactory`。ローカル LLM でプロンプトファイルを作るアプリ) の「PWC で開く」で、作ったファイルのフォルダを開き、作ったファイルを選んだ状態にします。そのまま生成するか、PrismLab に送って生成します。

- PWC はいくつでも起動できます (2026-11-26)。パイプ (`PromptWordCrafter-(ユーザー名)`) はどれか 1 つの窓 (最初に開いた窓。閉じたら残りの窓が 3 秒ほどで引き継ぐ) が持ち、前回終わらなかった生成ジョブの続きもその窓だけが聞きます。
- PWC が動いていれば、そのパイプに 1 行の JSON `{"cmd": "open", "from": "MuseFactory", "folder": "...", "select": ["..."]}` が届きます。動いていなければ `PromptWordCrafter.exe --open (JSON のパス)` で起動されます (読んだ JSON は消します)。
- 開いているフォルダと同じでも読み直します。未保存の編集があるときは、いつもどおり保存を確かめます (キャンセルすると開きません)。
- MuseFactory は生成に使うプロンプト `.txt` だけをフォルダの直下に置き、中間表現などは `.muse` フォルダ (サブフォルダ込みの生成でも `.` で始まるフォルダは飛ばします)、動画用のペアは `video` フォルダに置きます。

## 基本的な使い方

1. 上部のフォルダ欄で対象フォルダを指定します。
2. 「選択」ボタンでフォルダを選ぶか、フォルダ欄にパスを入力して Enter を押します。
3. 左側のファイル一覧から編集したいテキストファイルを選択します。
4. 右側の編集欄にファイル内容が表示されます。

対象になる拡張子は `.txt`, `.log`, `.md`, `.csv`, `.tsv`, `.json`, `.xml`, `.html`, `.htm`, `.css`, `.js`, `.py`, `.ini`, `.cfg`, `.conf`, `.yml`, `.yaml` です。

## 検索

検索文字列を入力して「検索」ボタンを押すと、現在表示中のファイル内を検索します。一致箇所はハイライト表示され、最初の一致箇所へスクロールします。

検索文字列を入力すると、左側のファイル一覧も自動的にスキャンされます（入力後 250ms 待ってから実行）。検索文字列を含むファイルは、淡色 `#edf5ef` でハイライト表示されます。

検索後は、置換ボタンと同じように左側のファイル一覧へフォーカスが戻ります。検索欄で Enter を押しても検索できます。編集欄でテキストを選択すると、選択した文字列が検索欄に自動的にコピーされます。

## 置換

検索文字列と置換文字列を入力して「置換」ボタンを押すと、現在表示中のファイルの編集欄内で一致箇所をまとめて置換します。置換は編集欄への変更なので `Ctrl+Z` で元に戻せます。内容を確認してから「保存」でファイルへ反映してください。

保存時は、初回だけ元ファイルと同じ場所に `.bak` バックアップを作成します。たとえば `sample.txt` を保存した場合、`sample.txt.bak` が作成されます。

検索・置換は大文字小文字を区別します。検索欄・置換欄では `Ctrl+Enter` で改行を入力でき、複数行の検索語も使えます。空白は NBSP と、改行は CRLF / CR / LF / U+2028 / U+2029 と同一視して判定します。

「フォルダ一括置換」ボタンは、フォルダ内の全ファイルを同じ判定で置換してファイルへ直接書き込みます（`.bak` を作成し、`Ctrl+Z` では戻せません）。

## 直接編集と保存

右側の編集欄は直接編集できます。編集後は「保存」ボタンで現在のファイルへ保存します。

ショートカットでも保存できます。

```text
Ctrl+S
```

保存時も、初回だけ `.bak` バックアップを作成します。

## 未保存の変更

未保存の編集がある状態で次の操作をしようとすると、保存確認が表示されます。

- 別のファイルを選択する
- フォルダを再読み込みする
- 別のフォルダを選ぶ
- アプリを閉じる

キャンセルを選ぶと操作は中止され、編集中のファイルに戻ります。

## ファイルのドラッグ&ドロップ

左側のファイル一覧から選択したファイルを Windows エクスプローラーへドラッグすると、そのままコピーできます。`Ctrl` / `Shift` で複数選択したファイルもまとめてドラッグコピーできます。

## テキストの名前の変更・削除・コピー・移動

ファイル一覧の右クリックで「コピー」「切り取り」「貼り付け」「フォルダへコピー...」「フォルダへ移動...」「エクスプローラーで開く」「名前の変更...」「ファイルを削除 (ごみ箱へ)」ができます（2026-11-26）。対象は選択中のすべて（選んでいなければ右クリックしたもの）。複数のときはメニューに件数が入ります。

- **コピー・切り取り・貼り付け**（エクスプローラーと同じ。ファイル一覧にフォーカスがあるときは `Ctrl+C` / `Ctrl+X` / `Ctrl+V`）: 貼り付けは今のフォルダへ（フォルダツリーの右クリック「このフォルダに貼り付け」ならそのフォルダへ）。同じ名前があれば聞かずに `名前 (1).txt`、`名前 (2).txt` … にするので、同じフォルダに貼ると複製になります（生成結果も `名前 (1)_t2i.png` のように付いてきます）。切り取ったものは貼り付けで移動し、同じフォルダに貼っても何もしません。クリップボードはエクスプローラーと同じ形なので、PWC でコピーしてエクスプローラーに貼る・エクスプローラーでコピーしたテキストを PWC に貼ることもできます（エクスプローラーで貼ったときはテキストだけが動きます）。貼り付けたものは一覧で選んだ状態になり、表示中のテキストはそのままです。
- **名前の変更**（ファイル一覧にフォーカスがあるときは `F2`）: 拡張子の前までを選んだ状態で名前の欄が出ます。生成結果（`名前_t2i.png` など）・説明の `.txt`・`.bak` の名前と生成の記録も合わせて変えます。表示中のテキストなら、保存していない編集もそのまま残ります（保存すると新しい名前に書きます）。同じ名前がある・使えない文字がある・テキストでない拡張子（一覧に出なくなる）のときは変えません。2 件以上を選んでいるときは、`F2` もメニューも「一括リネーム」になります。
- **フォルダへコピー... / フォルダへ移動...**: 行き先のフォルダと、同じ名前があるときの扱いをダイアログで選びます（下の項目）。
- **フォルダツリーへドラッグ**（エクスプローラーと同じ。2026-11-28）: ファイル一覧のテキスト（エクスプローラーからのテキストも）を左のフォルダツリーのフォルダの上で離すと、そのフォルダへ動かします。同じドライブなら移動、違うドライブならコピー。`Ctrl` を押しながらならコピー、`Shift` なら移動。行き先は青い枠で示し、ステータスバーに「離すと…へ移動します」と出します。閉じたフォルダの上で少し待つと開きます。同じ名前があれば貼り付けと同じく聞かずに `名前 (1).txt` にします。生成結果も一緒に動きます。
- **新しいフォルダー...**（2026-11-28）: フォルダツリーの右クリックでそのフォルダの中に、ファイル一覧の右クリック（一覧が空でも）か `Ctrl+Shift+N`（ツリーかファイル一覧にフォーカスがあるとき）で今のフォルダの中に作ります。名前は `新しいフォルダー`（あれば `新しいフォルダー (2)` …）を入れた欄が出るので、直して OK。使えない文字・同じ名前があるときは作りません。作ったあとも今のフォルダのままで、ツリーで新しいフォルダを見せます（テキストはドラッグなどで入れます）。

- **一緒に動かすもの**: そのテキストから生成した結果（画像・動画。`生成結果` フォルダと、前の置き場所のテキストと同じフォルダのもの）、`生成結果` フォルダの結果に付いている説明の `.txt`、保存のときに作った `.bak`。PrismLab の量産の出力（レシピの出力フォルダにあるもの）は動かしません（移動では PrismLab の記録の入口だけ付け替えます）。
- **削除**: すべてごみ箱へ送ります。ファイル一覧にフォーカスがあるときは `Del` でも消せます（押しっぱなしは無視）。1 件は確認なし、複数・ごみ箱に入らない場所（ネットワーク）・保存していない編集があるときだけ確認します。消したあとは同じ位置（＝次）のテキストを表示します。
- **フォルダへコピー・移動**: 行き先のフォルダを選びます（なければ作ります。前回の行き先を覚えます）。結果は行き先の `生成結果` フォルダへ入り、生成の記録も付け替え（移動）・写し（コピー）ます。コピーしたテキストでも生成結果の帯に結果が出ます。表示中のテキストに保存していない編集があれば、先に保存するか聞きます。
- 行き先に同じ名前のテキストがあるとき: 中身が同じならスキップ。中身が違うときは「別名で保存」（`名前 (2).txt`。結果の名前の頭もそれに合わせます）/「スキップ」/「上書き」をダイアログで選びます。結果の画像は上書きせず、ぶつかれば番号を付けます。途中では何も聞かず、スキップ・上書き・別名・失敗があったときだけ終わってからまとめて知らせます。
- コピー・移動の間は画面を操作できません（裏で動かし、終わったらステータスバーに結果を出します）。
- J-Rate の標準 (`docs\ui-standard.md` 8 章) では「評価で絞り込んだ一覧の全部」をコピー・移動しますが、PWC には評価がないので選択中のものを対象にしています（2026-11-26 利用者の決定）。

## 設定保存

アプリ終了時に次の設定が `promptwordcrafter_settings.json`（実行ファイルと同じフォルダ）に保存されます。

- 最後に開いたフォルダ
- 検索文字列
- 置換文字列
- ウィンドウの位置とサイズ
- 翻訳 (AI) のオン/オフ、訳す向き、サーバーURL、モデル名
- エンハンサー (AI) で選んでいるプリセットと、LLM のモデル名
- 項目整理と盛るの上限、コピー・移動の前回の行き先と同じ名前のときの扱い
- 「AIに指示」の最近の指示 (20 件)

## 対応エンコーディング

ファイル読み込み時は次の順で文字コードを判定します。

```text
utf-8-sig, utf-8, cp932, utf-16, latin-1
```

保存時は、読み込み時に判定された文字コードで保存します。

## フォルダツリー

ファイル一覧の左側にフォルダツリーを表示します。フォルダをクリックすると、そのフォルダ（直下のみ、非再帰）がファイル一覧に反映されます。

## 一括操作

コントロールバーの下に一括操作ボタンがあります。いずれも対象はフォルダ直下のファイルのみで、サブフォルダの中身は対象になりません。

- **新規ファイル**: 現在のフォルダに空のテキストファイルを作成します。ファイル名は一覧の最後のファイル名の末尾の番号を +1 したもの（桁数・拡張子は維持。例: `haikei2-010.txt` → `haikei2-011.txt`）が初期表示され、変更もできます。拡張子を省略すると `.txt` になります。
- **一括リネーム**: ファイル一覧で複数選択している場合はその選択ファイル、未選択（1件以下の選択）の場合はフォルダ内の全ファイルを対象に、プレフィックス・開始番号・桁数を指定して連番形式（例: `scene_001.txt`）にリネームします。プレビューを見ながら調整できます。
- **文字列追加**: 指定した文字列をファイルの先頭または末尾に追加します。対象は「現在のファイルのみ」または「フォルダ内の全ファイル」から選べます。追加時も `.bak` バックアップが作成されます。
- **文字列削除**: 指定した文字列をファイルから削除します。対象は「現在のファイルのみ」または「フォルダ内の全ファイル」から選べます。削除時も `.bak` バックアップが作成されます。
- **.bakファイル削除**: 現在のフォルダ直下にある `.bak` ファイルをまとめて削除します。件数を確認するダイアログが表示されます。
- **文字列成型**: 現在編集中のファイルの内容に対して、「。」「.」の直後に改行を追加します。整形後は編集欄に反映されるだけなので、内容を確認してから「保存」してください。
- **項目整理** (AI。2026-11-26): 編集欄の本文をローカル LLM に渡して、項目ごとに分けて書き直してもらいます。項目は `[登場人物]` `[衣装]` `[ポーズ・動作]` `[背景・小道具]` `[構図]` `[照明・画風]` の順で、どれにも当てはまらない内容は AI が内容から項目名（`[表情]` など）を作ってまとめ、後ろに置きます。中身のない項目は出しません。
  - 本文の言葉はそのまま（英語は英語、日本語は日本語。訳さない・足さない・落とさない）。重み付け `(word:1.2)` や `<lora:...>` もそのまま残すよう指示しています。AI が「[衣装] 黒いジャケット」のように同じ行に書いてきたときは、項目名の行と内容の行に分けます。
  - 結果は編集欄にそのまま入ります（`Ctrl+Z` 1 回で戻せます。ファイルへは「保存」で）。整理している間に表示中のテキストを替えたり本文を書き換えたりしたときは、編集欄には入れずクリップボードにコピーします。
  - **本文が空のとき**は AI を使わず、項目名だけを並べて入れます（各項目の下に 1 行ずつ空けてあり、最初の項目の下にカーソルを置きます）。
- **AIに指示** (AI。2026-11-27): 押すと指示を入れる窓が出ます。「このプロンプトの背景を紅葉の森に変えてください。」のように書いて「書き換える」（Ctrl+Enter）を押すと、編集欄の本文を指示どおりに書き換えます。
  - チャットで「下記のプロンプトを、次の指示どおりに書き直してください。指示: （入れた指示）プロンプトのみを出力してください。」と頼んだときと同じ頼み方をします（指示文などで縛らないので、全体を書き直す指示もそのまま効きます）。Markdown の装飾は付けないよう頼み、それでも付いてきたコードブロック・引用符・太字の `**`・先頭の「書き直したプロンプト:」のような見出しの行は外します。
  - 結果の入り方は項目整理と同じです（`Ctrl+Z` 1 回で戻せる。ファイルへは「保存」で。書き換えている間に表示中のテキストや本文が変わったら、編集欄には入れずクリップボードへ）。
  - 窓には前回の指示を入れてあり、「最近の指示から選ぶ...」で最近の 20 件から選び直せます。
  - AI の接続とモデルは「盛る」と同じもの（エンハンサーの設定）を使います。
  - 接続先とモデルは「盛る」と同じもの（エンハンサーの「設定」のサーバーURL とモデル）を使います。
  - 隣の「**上限**」で結果の長さの上限（おおよそのトークン数。0 で上限なし）を決められます。下の「トークン数」の節。
- **翻訳して書き出す** (AI。2026-11-26): 表示中のテキストの本文（保存前の編集も含む）を訳して、同じフォルダの別のファイルに UTF-8 で書き出します。元のファイルは変えません。ちょっと見るだけなら今までどおり「翻訳 (AI)」の小窓を使います。
  - 名前は訳した先の言語で `名前_en.txt` / `名前_ja.txt`。あれば `名前_en (1).txt` … にします。書き出したファイルは一覧に足し、表示はそのままです。
  - 訳す向きは翻訳の小窓と同じです（ふだんは自動: 日本語 → 英語、それ以外 → 日本語。小窓の「日本語に」「英語に」を押してあればその向き）。接続先とモデルも「翻訳の設定」のものです。

## 生成 (PrismLab のレシピ)

生成の設定はすべて PrismLab で行い、PromptWordCrafter は PrismLab が「ほかのアプリに出す」にしたレシピを選んで生成するだけです（2026-11-22。PrismLab の `docs\spec.md` 6 章）。前の「生成する」「生成ジョブ」「生成の設定」「図で設定」は外しました。

- 上の「**生成 (PrismLab のレシピ)**」の段に、レシピのボタンが並びます。テキストファイルを選んで（なければ表示中のもの）ボタンを押すと、すぐ生成が始まります（30 件を超えるときだけ確かめます）。テキストからは始められないレシピ（画像の要るステップがあるもの）は押せない色になり、指を置くと理由が出ます。
- 生成は PrismLab が画面を出さずに裏で動かします（動いていなければ裏で起動し、タスクトレイに出ます。終わって何もなければ閉じます）。
- 左の「**台: …**」で、このアプリで使う ComfyUI を 3 台まで選びます（台ごとに使う / 使わない）。台はアプリごとです。台の空きは PrismLab が数え、量産ラインと合わせて 1 台に 2 件までです。
- 段の下に進み具合が出ます（「▶「画像 → 動画」4/10 件 (実行中 2・待機 4)」、繋がらない台、終わったら「✓ … 完了」）。「**中止...**」で止められます（出来たものは残します）。
- 「**PrismLab で直す...**」で PrismLab の画面を出します。レシピの中身・出すレシピはそこで決めます。
- ファイル一覧の右クリック: 「PrismLab のレシピで生成 ▸」（選択中のファイル）・「一覧のファイルをレシピで生成 ▸」・「生成時の設定...」・「PrismLab に送る ▸」。
- フォルダツリーの右クリック: 「このフォルダのテキストをレシピで生成 ▸」・「サブフォルダも含めてレシピで生成 ▸」（`.` で始まる隠しフォルダと `生成結果` フォルダはたどりません）・「PrismLab に送る ▸」・「このフォルダの生成結果を「生成結果」フォルダへ移す...」（前の版でテキストと同じフォルダに保存した生成結果を移します。説明の `.txt` と生成の記録も付け替えます）。
- 出来たファイルはテキストファイルのフォルダの中の `生成結果` フォルダに `(元の名前)_t2i.png` / `(元の名前)_video.mp4` などで入り、生成結果の帯に出ます。記録は PrismLab に残ります。
- 「**生成時の設定...**」: 結果の帯や右クリックから、どの設定で出来たか（レシピ名と何番目のステップか、入口のテキスト、ワークフロー、送ったプロンプト、盛ったプロンプト）を見られます。「この設定で生成する...」は出しません。
- 前の版の生成ジョブが残っていれば、起動したときに「続きから始める / ジョブを中断」を聞きます（続けたものの結果は前と同じく受け取ります）。

### 生成結果

編集欄の下に、表示中のテキストから生成した画像・動画のサムネールを新しい順に横一列で並べます（ホイールで横スクロール）。動画には ▶、今の本文とは違う前の本文で生成したものには「旧」の印が付きます。

- 結び付けは生成の記録を正にします。記録のないものは、`生成結果` フォルダとテキストと同じフォルダ（前の置き場所）から、名前が `(テキストの名前)_t2i` / `_video` で始まるファイルを拾います（この場合「旧」の判定はしません）。
- カーソルを乗せて少し待つと、一覧の上に大きく表示します（PrismLab の量産ラインと同じ。2026-11-28 にクリックで出す形から変えました）。出ているあいだに隣のサムネールへ移るとすぐ替わり、離れる・クリック・ホイール・キー・右クリック・ほかのウインドウに移ると消えます。動画は音なし・繰り返しで再生します。拡大の下に名前・大きさと、PrismLab のレシピ・生成した日時・ワークフロー・「前の本文で生成」などの説明を出します（サムネールのツールチップはやめました）。
- ダブルクリック / `Enter` で関連付けられたアプリで開きます。右クリックで「開く」「生成時の設定...」「エクスプローラーで開く」「ファイルを削除 (ごみ箱へ)」。「PrismLab に送る」で、選んでいる画像 (動画は除く) を PrismLab の量産のレシピの入口か、開いている物語 (新しいシーン。1 枚なら選んでいるシーンの元画像・リファレンス・ラストフレームも) に送れます (J-Rate と同じ項目。新しいシーンは作った順に足します)。「物語: バッチに足す...」で、PrismLab の物語のバッチの最初の画像にもできます (1 枚ごとに 1 件。PrismLab で設定の窓が開きます)。`Del` でも削除できます（複数のときだけ確認）。
- サムネールを他のアプリへドラッグすると、ファイルとして渡せます（コピーのみ）。
- 一括リネームでテキストの名前を変えると、生成結果のファイル名（`旧の名前_t2i.png` → `新しい名前_t2i.png`）と生成の記録も合わせて変えます。`生成結果` フォルダの結果に付いている説明の `.txt` と、その結果を元画像にした ImageMimicArt の記録も付け替えます。エクスプローラーで名前を変えた場合も、送った本文が今の本文と同じ記録から見つけます。
- 接続先・ワークフロー・ベースプロンプト・エンハンサー・LLM のサーバーURL は `%APPDATA%\GenCommon\` に置き、J-Rate・ImageMimicArt と共有します（どのアプリで変えても、ほかのアプリに効きます）。セット・前回選んだもの・生成の記録・ジョブは `%APPDATA%\PromptWordCrafter\` です。エクスポートした設定は 3 つのアプリで互いにインポートできます。
- 「生成の設定」の接続先のタブで、接続先ごとに「ワークフローのフォルダ」（`\\RAVEN\SharBox\comfyui-api\kiwi` など）を決めると、そのフォルダにあるワークフローはその台用として扱います。一覧の名前の後ろに［KIWI］のように台の名前が付き、生成の画面でワークフローを選ぶと接続先もその台になります。台が違う組み合わせのときは注意を出します。ワークフローのタブの「フォルダから登録...」で、フォルダにあるまだ登録していない JSON をまとめて登録できます（名前はファイル名）。
- 「生成の設定」の「共有の置き場所...」で、共有するものの置き場所をネットワークの共有フォルダ（`\\RAVEN\SharBox\GenCommon` など）にできます。ほかの PC でも同じフォルダにすると、PC の間でも同じ設定になります。この PC の今の設定のうち、そのフォルダにないものだけを足します。`%APPDATA%\GenCommon\` には最後に読めた内容の写しを残し、フォルダに繋がらないときはそれを表示します（その間は変更を保存しません）。使用中・前回選んだものは PC ごとで、ほかの PC で並べ替えても同じものを指し続けます。
- 生成と読み取りの部品は ImageMimicArt と共通の `..\GenCommon\gencommon` を使います（このフォルダと同じ `AI_projects` に並べて置きます。EXE を作るときも取り込みます）。決まりごとは J-Rate の `docs\generation-standard.md`。

## 翻訳 (AI・見るだけ)

コントロールバーの「翻訳 (AI)」グループで「翻訳する」をオンにすると、表示中のテキストの訳を編集欄の右下の小窓に出します。ファイルを切り替えるたびに訳し直します（訳が出るまで少し時間がかかります）。訳はファイルには書き込みません。

- 訳す向きはふだん AI が判別します（日本語以外 → 日本語、日本語 → 英語）。うまく判別されないとき（英語 → 英語になるなど）は、小窓の「日本語に」「英語に」を押すと、訳す先をはっきり指示して訳し直します。押したボタンはオンのまま残り、ファイルを切り替えてもその向きで訳します。もう一度押すと自動判別に戻ります。タグの区切り、`(word:1.2)` のような重み付け、`<lora:...>` などの記法はそのまま残すよう指示しています。
- 接続先は LM Studio などの OpenAI 互換 API です。「翻訳の設定」でサーバーURLとモデル名を変えられます（既定は TranslateText と同じ `http://192.168.11.6:1234/v1` / `qwen2.5-14b-instruct-uncensored`）。「モデル取得」「接続テスト」もあります。
- ファイルを続けて切り替えたときは、止まったところのファイルだけを訳します。一度訳した本文は覚えておき、もう一度は依頼しません。
- 小窓のコピーアイコンで訳を丸ごとクリップボードにコピーします（押すと少しの間 ✓ に変わります）。一部だけなら本文を選んで `Ctrl+C` でもコピーできます。
- 小窓の「再翻訳」で編集欄の今の内容（保存前の編集も含む）を訳し直します。「×」で翻訳をオフにします。

## エンハンサー (AI・見るだけ)

コントロールバーの「エンハンサー (AI)」グループでエンハンサーを選んで「盛る」を押すと、編集欄の今の内容（保存前の編集も含む）をローカル LLM に渡して書き足してもらい、結果を編集欄の右上の小窓に出します。ファイルには書き込みません。コピーアイコンでコピーして使います。

- 生成 AI のモデルごとに推奨される書き方が違うので、「設定」でモデルごとのエンハンサーを最大 20 個登録して切り替えます。1 つのエンハンサーは、名前・指示文 (system)・送る文の雛形 (user)・temperature です。
  - 指示文には、モデルごとに推奨されている指示文をそのまま貼ります。
  - 雛形の `{prompt}` が編集欄の内容に置き換わります（ふつうは `{prompt}` だけで十分です）。`{prompt}` がないときは、雛形のあとに編集欄の内容を付けて送ります。
  - 登録は「プリセットを保存」「削除」「▲ 上へ」「▼ 下へ」でその場で書き込みます（キャンセルしても残ります）。`%APPDATA%\GenCommon\enhancer_presets.json` に保存します (3 つのアプリで共有)。初めて使うときは、1・2 番に例（自然文・タグ）が入っています。
- 接続先は「翻訳の設定」のサーバーURLを使います。LLM のモデルは翻訳と別に選べます（初めは翻訳と同じモデル）。
- 小窓の「もう一度」で盛り直します（毎回違う結果になります）。盛っている間は「盛る」を押せません。結果はファイルを切り替えても残るので、新しいファイルに貼ることもできます。「×」で閉じます。
- 結果の全体を囲むコードブロックや引用符、`<think>...</think>` は取り除きます。
- 登録したエンハンサーは、生成するときにも使えます（「生成 (ComfyUI)」の章）。
- 「盛る」の隣の「**上限**」で、盛った結果の長さの上限（おおよそのトークン数。0 で上限なし）を決められます。この画面の「盛る」だけに効きます（PrismLab のレシピや J-Rate の盛るには効きません。2026-11-26 利用者の決定）。小窓の見出しに結果のおおよそのトークン数が出て、打ち切られたときは「(上限で打ち切り)」と出ます。

## トークン数 (2026-11-26)

- ステータスバーの右端に、編集欄の本文のおおよそのトークン数（「約 120 トークン」）を出します。打つたびに数え直します。
- 数え方は LLM 系の目安です（LM Studio の Qwen 系の数に合わせました）: 英語などの単語は 1 語で約 1（長い語は 6 文字ごとに 1）、数字は 3 桁ごとに 1、漢字・かなは 1 文字で約 0.65、記号は 1 文字で 1。生成のモデルの CLIP・T5 は数え方が違います（英語で 1〜3 割多め、T5 の日本語はずっと多め）。
- 「項目整理」と「盛る」の「上限」: 「約 N トークン以内で（長ければ大事なところを残して縮める。言語は変えない）」と AI に指示したうえで、返事を N の 1.5 倍 + 32 トークンで打ち切ってもらいます（指示を守らないときの歯止め。ぴったりで切ると文が途中で切れるので余裕を持たせています）。エンハンサーの指示文が長く書くよう求めているときは、AI が指示を守らず打ち切りで止まることがあります。考える過程を出すモデルで、考えている途中に上限に来たときはエラーにします。
- 上限の値は `promptwordcrafter_settings.json` に保存します（`organize_limit` / `enhance_limit`）。

## MiniMax H3 タグのハイライト

`<d> ～ </d>` のブロックは常時ハイライト表示されます（複数行にまたがる場合も対応）。タグ内の `[...]`（角括弧）で囲まれた部分は、セリフ文字部分としてさらに青色で強調表示されます。
